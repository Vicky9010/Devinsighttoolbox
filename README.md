# Devinsighttoolbox

**DevInsightToolbox** is a web-based utility designed for developers to gain quick insights into IP & system information and experiment with JavaScript code in real-time. This project combines network utilities, code execution, and dark-mode theming into a sleek developer-friendly interface.

---

## 🚀 Features

- 🌍 **IP & System Info Lookup**  
  Enter any IP address to fetch geolocation and network data using [ipapi.co](https://ipapi.co), with map visualization via Leaflet.

- 🧪 **Live JavaScript Debugger**  
  Write, run, save, and reload JavaScript code snippets directly in your browser using the embedded CodeMirror editor.

- 🌓 **Dark Mode Toggle**  
  Switch between light and dark themes seamlessly.

- 💾 **Persistent Code Storage**  
  Save and reload code using `localStorage` for continuing work without backend dependencies.

---

## 🌐 Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Libraries & APIs:**
  - [Bootstrap 5](https://getbootstrap.com) – Styling & Layout
  - [Leaflet](https://leafletjs.com) – Map integration
  - [ipapi.co](https://ipapi.co) – IP geolocation API
  - [CodeMirror](https://codemirror.net) – JavaScript editor with syntax highlighting
